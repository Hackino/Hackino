Full-stack software engineer with 6+ years of experience, owning products from architecture to production — build, testing, CI/CD, deployment, releases, and support. I build React Native and Flutter apps and Next.js / React web products on Supabase and Firebase backends, directing AI coding agents (Claude Code, Cursor, GitHub Copilot) while I own the architecture, the code review, and the release.

## &nbsp;◢&nbsp; How I Work

```typescript
const engineering = {
  principles: [
    "Own it from architecture to production",
    "Agents write the code — I own the design, the review, and the release",
    "Every change goes through CI, tests, and code review",
    "Roll out in phases and watch the crash dashboard",
    "Small modules, hard boundaries",
  ],

  ship: (idea: Idea): Release =>
    idea
      .scope()
      .architect()
      .build({ withAgents: true })
      .review()

};
```
